# ClassUpdates promo video

A 42-second walkthrough of the class board, made with
[Remotion](https://www.remotion.dev) (React for video), in two formats:

| File | Size | For |
|------|------|-----|
| `renders/class-updates-landscape.mp4` | 1920 x 1080 | Laptops, YouTube |
| `renders/class-updates-vertical.mp4` | 1080 x 1920 | Phones, WhatsApp status |

Nine scenes: the problem (one PDF a day), the passcode, the Daily Diary,
ticking homework, flashcards, the Weekly Overview, circulars, and the address.

## Content

- The phone screens in `public/screens/` are screenshots of the live site's
  **sample** board ("See a sample"), so no real class content appears.
- The music, `public/music.m4a`, is generated by `scripts/make_music.py`
  (a calm C-G-Am-F loop), so there is no licence to track. Replace the file to
  use another track.

## Editing and rendering

```bash
cd video
npm install
npm run dev        # Remotion Studio at http://localhost:3000
```

Each scene is its own file in `src/landscape/` and `src/vertical/`, and its own
composition in the Studio, where text, timing and positions can be edited.
`LandscapeVideo.tsx` and `VerticalVideo.tsx` join them.

```bash
npx remotion render ClassUpdatesVideo renders/class-updates-landscape.mp4
npx remotion render ClassUpdatesVertical renders/class-updates-vertical.mp4
```

This folder is separate from the app: its packages are not the app's, and
nothing here is deployed.
